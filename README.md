# Tiffin Service Demo

Concept website for a GTA tiffin (Meal delivery) service — built as a sales demo and portfolio piece.

## What's inside
- Interactive menu explorer with weekly meal plans
- Plan selection, pricing, and rewards sections
- Contact flow, fully responsive with light/dark mode

## Live demo
https://cddprototype.netlify.app

## Tech
Single-file HTML/CSS/JavaScript site.
